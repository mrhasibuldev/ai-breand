## 1. Execution notes

The following SQL is the production-oriented bootstrap specification. It is intentionally written as reviewable text rather than an application migration generated by an ORM.

- Run it only through a versioned migration tool and a least-privilege migration identity.
- `CREATE EXTENSION IF NOT EXISTS`, `CREATE SCHEMA IF NOT EXISTS`, `CREATE TABLE IF NOT EXISTS`, named indexes, and `CREATE OR REPLACE FUNCTION` make bootstrap operations repeatable. The migration runner remains the source of truth for version ordering.
- The `nexus` schema is used for product data. The selected provider, region, engine major, roles/grants, encryption keys, RLS/session identity, and backup configuration remain deployment decisions.
- No SQL below stores passwords, raw tokens, provider payloads, raw prompts, raw responses, or clinical/diagnostic data.
- `bytea` fields marked encrypted are ciphertext produced by the application/data-service encryption boundary. SQL cannot prove that a byte sequence is encrypted.

## 2. Bootstrap, schema, and common functions

```sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE SCHEMA IF NOT EXISTS nexus;
SET search_path = nexus, public;

CREATE OR REPLACE FUNCTION nexus.set_updated_at()
RETURNS trigger
LANGUAGE plpgsql
AS $$
BEGIN
    NEW.updated_at = clock_timestamp();
    RETURN NEW;
END;
$$;

CREATE OR REPLACE FUNCTION nexus.prevent_history_mutation()
RETURNS trigger
LANGUAGE plpgsql
AS $$
BEGIN
    RAISE EXCEPTION 'Append-only history cannot be updated or deleted: %.%', TG_TABLE_SCHEMA, TG_TABLE_NAME;
END;
$$;
```

## 5. Conversation, message, and memory tables

```sql
CREATE TABLE IF NOT EXISTS nexus.conversations (
    id                  uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    account_id          uuid NOT NULL,
    status              text NOT NULL DEFAULT 'active',
    title               varchar(160),
    started_at          timestamptz NOT NULL DEFAULT clock_timestamp(),
    ended_at            timestamptz,
    deleted_at          timestamptz,
    CONSTRAINT conversations_account_fk FOREIGN KEY (account_id)
        REFERENCES nexus.accounts (id) ON DELETE RESTRICT,
    CONSTRAINT conversations_account_id_uk UNIQUE (account_id, id),
    CONSTRAINT conversations_status_ck CHECK (status IN ('active', 'ended', 'deleted')),
    CONSTRAINT conversations_end_order_ck CHECK (ended_at IS NULL OR ended_at >= started_at),
    CONSTRAINT conversations_deleted_state_ck CHECK (status <> 'deleted' OR deleted_at IS NOT NULL)
);

CREATE INDEX IF NOT EXISTS conversations_account_started_idx
    ON nexus.conversations (account_id, started_at DESC);

CREATE TABLE IF NOT EXISTS nexus.messages (
    id                  uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    conversation_id     uuid NOT NULL,
    sequence_no         integer NOT NULL,
    sender_role         text NOT NULL,
    content             bytea NOT NULL,
    content_status      text NOT NULL DEFAULT 'active',
    created_at          timestamptz NOT NULL DEFAULT clock_timestamp(),
    deleted_at          timestamptz,
    CONSTRAINT messages_conversation_fk FOREIGN KEY (conversation_id)
        REFERENCES nexus.conversations (id) ON DELETE RESTRICT,
    CONSTRAINT messages_conversation_sequence_uk UNIQUE (conversation_id, sequence_no),
    CONSTRAINT messages_sequence_ck CHECK (sequence_no > 0),
    CONSTRAINT messages_role_ck CHECK (sender_role IN ('user', 'assistant')),
    CONSTRAINT messages_content_ck CHECK (octet_length(content) > 0),
    CONSTRAINT messages_content_status_ck CHECK (content_status IN ('active', 'redacted', 'deleted', 'blocked')),
    CONSTRAINT messages_deleted_state_ck CHECK (content_status IN ('deleted', 'redacted') OR deleted_at IS NULL OR content_status = 'blocked')
);

CREATE INDEX IF NOT EXISTS messages_conversation_sequence_idx
    ON nexus.messages (conversation_id, sequence_no);

CREATE TABLE IF NOT EXISTS nexus.memory_records (
    id                      uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    account_id              uuid NOT NULL,
    consent_record_id       uuid NOT NULL,
    source_message_id       uuid,
    category                text NOT NULL,
    purpose                 varchar(160) NOT NULL,
    value                   bytea NOT NULL,
    status                  text NOT NULL DEFAULT 'approved',
    content_fingerprint     varchar(128),
    approved_at             timestamptz NOT NULL DEFAULT clock_timestamp(),
    revoked_at              timestamptz,
    expires_at              timestamptz,
    deleted_at              timestamptz,
    CONSTRAINT memory_records_account_fk FOREIGN KEY (account_id)
        REFERENCES nexus.accounts (id) ON DELETE RESTRICT,
    CONSTRAINT memory_records_consent_fk FOREIGN KEY (consent_record_id)
        REFERENCES nexus.consent_records (id) ON DELETE RESTRICT,
    CONSTRAINT memory_records_source_message_fk FOREIGN KEY (source_message_id)
        REFERENCES nexus.messages (id) ON DELETE RESTRICT,
    CONSTRAINT memory_records_category_ck CHECK (category IN ('name', 'age_band', 'wellness_goal', 'preference', 'daily_habit', 'plan_preference')),
    CONSTRAINT memory_records_purpose_ck CHECK (char_length(btrim(purpose)) > 0),
    CONSTRAINT memory_records_value_ck CHECK (octet_length(value) > 0),
    CONSTRAINT memory_records_status_ck CHECK (status IN ('approved', 'revoked', 'expired', 'deleted')),
    CONSTRAINT memory_records_approved_state_ck CHECK (status <> 'approved' OR approved_at IS NOT NULL),
    CONSTRAINT memory_records_revoked_state_ck CHECK (status <> 'revoked' OR revoked_at IS NOT NULL),
    CONSTRAINT memory_records_expiry_order_ck CHECK (expires_at IS NULL OR expires_at > approved_at),
    CONSTRAINT memory_records_revoke_order_ck CHECK (revoked_at IS NULL OR revoked_at >= approved_at),
    CONSTRAINT memory_records_deleted_state_ck CHECK (status <> 'deleted' OR deleted_at IS NOT NULL)
);

CREATE INDEX IF NOT EXISTS memory_records_account_status_idx
    ON nexus.memory_records (account_id, status, category);

CREATE UNIQUE INDEX IF NOT EXISTS memory_records_active_fingerprint_uk
    ON nexus.memory_records (account_id, content_fingerprint, purpose)
    WHERE status = 'approved' AND content_fingerprint IS NOT NULL;

CREATE INDEX IF NOT EXISTS memory_records_expiry_idx
    ON nexus.memory_records (expires_at)
    WHERE expires_at IS NOT NULL AND status = 'approved';

CREATE INDEX IF NOT EXISTS memory_records_consent_idx
    ON nexus.memory_records (consent_record_id);

CREATE INDEX IF NOT EXISTS memory_records_source_message_idx
    ON nexus.memory_records (source_message_id)
    WHERE source_message_id IS NOT NULL;
```

## 8. DDL-to-design notes

1. The 21 tables map one-to-one to the approved ERD and dictionary; no billing, clinical, wearable, location, household, or organization table is added.
2. `accounts.email_normalized` is unique for every non-purged account, matching the logical “non-purged” rule. `auth_issuer` + `auth_subject` is always unique.
3. Active daily plans are unique by account/date through a partial unique index. Archived/deleted history may coexist.
4. Active memory duplicate prevention uses an optional fingerprint and never indexes plaintext `value`.
5. `messages` inherit ownership from `conversations`; a future physical change that duplicates `account_id` on messages would be a proposed domain-model change and requires review.
6. `scope` permits the approved `memory` or `account` values; application validation determines which scope is legal for each request type.
7. `notification_preferences.email_enabled` and `push_enabled` default to safe-off, and `reminders.channel` is restricted to the approved MVP value `in_app`; adding another channel requires consent/provider approval and a reviewed migration.
8. Exact IANA timezone validation, recurrence semantics, current-consent derivation, role authorization, safety policy ownership, retention, and provider deletion guarantees are not encoded as invented SQL policy.
9. Logical “current local date” defaults for goals, plans, and check-ins are supplied by the domain service using the account timezone; a server-timezone SQL default would be unsafe.
10. `ON DELETE RESTRICT` is intentional. V1 account purge keeps a minimal pseudonymized account anchor so immutable audit/history references survive without direct identity; purge remains an ordered lifecycle operation.

## 10. Known implementation boundary

The database can enforce structural integrity, but it cannot by itself prove that a `bytea` value is encrypted, that a consent record is the latest granted record, that a provider has deleted a payload, that an operator has an approved role, or that a user is in an allowed launch geography. Those checks belong to the policy/service layer and are explicitly listed in [`06-database-validation.md`](06-database-validation.md) as required cross-layer controls.

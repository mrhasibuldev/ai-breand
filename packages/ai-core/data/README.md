# NexusAI Brain — ডাটা কালেকশন ও ট্রেনিং গাইড

## প্রথম ধাপ: ডাটা প্রস্তুত করা

আপনার ডাটা একটি ফোল্ডারে রাখুন (উদাহরণমূলে বাংলা+ইংরেজি মিক্সড টেক্স):
```
packages/ai-core/data/user_data/
├── bengali_texts.txt
├── english_texts.txt
└── conversations.json
```

## দ্বিতীয় ধাপ: ডাটাসেট প্রস্তুত করা

এই আপনার ডাটা রেডি হয়ে গেছে, এই ট্রেনিং ডাটাসেট তৈরি করুন:

```bash
cd packages/ai-core/data
python prepare_dataset.py --input user_data/ --output custom_training --format auto
```

এটি তৈরি করলে স্বযংমতিক হবে:
- `custom_training/train.json` (৮০% ডাটা)
- `custom_training/validation.json` (২০% ডাটা)

## তৃতীয় ধাপ: ট্রেনিং চালান

ট্রেনিং স্ক্রিপ্ট আপডেট করুন:

```bash
cd packages/ai-core
python training/train.py \
  --data data/custom_training \
  --output models/checkpoints \
  --epochs 10 \
  --batch_size 8 \
  --learning_rate 0.001
```

## গুরুত্বপ বিবেচনা

### কম ডাটা (< ১০০ স্যাম্পল)
- সমস্য: খুব ছোট মডেল কাজানো যাবে
- ফলব্যাক: সীমিত ট্রেনিং

### মাঝারি ডাটা (১০০-১০০০ স্যাম্পল)
- সম্যস: ভাল মডেল কাজানো যাবে
- ফলব্যাক: উন্নত মান উন্নতি

### বড় ডাটা (১০০০০+ স্যাম্পল)
- সম্যস: সেরা মডেল কাজানো যাবে
- ফলব্যাক: উন্নত মান উন্নতি
- প্রয়োজন: ব্যাচ করে ভাগ নিতে ভাগ রাখতে পারে

## ট্রেনিং পরে টেস্টিং

ট্রেনিং শেষে নতুন চ্যাট ইন্টারফেসে টেস্ট করুন:
- "তোমার নাম কি?"
- "কী করতে পারো?"
- "বাংলায় গর্ব কী?"

## সমস্যা

- **কমপক্ষমে ১০০+ স্যাম্পল ডাটা লাগবে** - ভাল মডেল কাজানোর জন্য
- **বাংলা ও ইংরেজি দুই ভাষার ডাটা** - উন্নত সাপোর্ট
- **বৈচিত্র কথোপকথন** - প্রশ্ন ও উত্তর আকারে
- **অপনার নিজের ডাটা** - কপিরাইট থাকবে, কোনো এক্সটার্নাল এপিআই ব্যবহার করবে না

## সাহায্য লাগবে

কোনো সমস্যা হলে চ্যাট ইন্টারফেসে বলুন:
- ডাটা ফরম্যাট
- ডাটা প্রস্তুত
- ট্রনিং স্ক্রিপ্ট
